MAUSAM SmartHome V3

This is a beginner-friendly HTML/CSS/JavaScript prototype for the SIH Mausam personalization concept.

V3 changes:
- Fixed the Why? explanation popup.
- Close button works reliably.
- Clicking outside the popup closes it.
- Pressing Escape closes it.
- Added a clear Got it button.
- Prevents page scrolling while the popup is open.
- Polished modal animation and spacing.
- Cleaner top navigation and cards.
- Multiple personalization choices remain supported.
- Added icons for weather metrics and navigation.
- Added simple toast messages for demo interactions.

How to run:
1. Extract the folder.
2. Open it in VS Code.
3. Install/use Live Server if available.
4. Right-click index.html -> Open with Live Server.
5. Or double-click index.html for a basic local preview.

Note: Weather values are demo data for the SIH prototype. Replace them with authorized live data/API feeds in the backend implementation.
